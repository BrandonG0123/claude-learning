# Comic Neue

The handwriting font the animate skill's cut-paper tags use on Linux (it is in the kit's `HAND` font stack:
"Ink Free", "Segoe Print", "Bradley Hand", "Chalkboard SE", "Comic Sans MS", "Comic Neue", cursive).
Claude Code cloud containers ship no handwriting font, so `.claude/hooks/session-start.sh` installs these
files for the session user and refreshes the font cache.

Comic Neue by Craig Rozynski and the Comic Neue Project Authors, SIL Open Font License 1.1 (see LICENSE).
TTFs converted from the `@fontsource/comic-neue` 5.3.0 woff2 files (latin subset): 300, 400, 700 and 700 italic.
